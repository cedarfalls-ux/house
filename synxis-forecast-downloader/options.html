Daily automatic download

from to
The download happens once a day inside this window (default 12:00 AM – 11:00 AM).
It starts when SynXis is open and logged in and nobody has moved the mouse or typed for this many seconds.
If a download fails it tries again later, up to this many times a day.

Where to save

Type any folder name. Use / for sub-folders, e.g. Hotel Reports/Forecast. It is created automatically.
Tokens: {date} 2026-10-18, {time} 0215, {range} NextYear, {YYYY} {MM} {DD} {HH} {mm}
Chrome only lets extensions save inside your Downloads folder. To save on another drive (for example D:\Reports), change Chrome's download location, and this folder will be created there.

So it keeps working every day, even after a restart

  1. Turn on "Continue running background apps when Google Chrome is closed" in . Chrome then starts by itself when the computer starts.
  2. Set On startup → "Continue where you left off" in so the SynXis tab opens again after a restart.
  3. Stay logged in to SynXis in this Chrome profile (right hotel selected).
  4. Right-click the extension icon for Download Forecast now, Cancel and Show last file.

Activity log

If downloads fail: keep the SynXis tab open, click Copy debug info and paste it to whoever supports this extension. It shows what the extension can see on the SynXis page (no passwords).
